基本
來源
SQL Server 上的資料庫名稱，檔案路徑自動取自來源的 sys.master_files； 留空 = 檔案磁碟分享模式（跳過所有 SQL 步驟，目標只掛碟 + 指派碟號）
留空時每輪自動掃描，來源 VM 搬 datastore 後自動跟隨
目的
目標端只保留最新一份；換手成功才刪上一份，複本保持關機
資料碟副本可留空；整機同步必填（複本落點）
clone 掛載後指派的碟號，不可與目標 VM 既有磁碟衝突
xvc 由來源側主機發起，其版本不得高於目的端 vCenter
版本不相容（如 8.0 主機 → 7.0 vCenter）請選 OVF 串流； vTPM/加密 VM 只能走 XVM
